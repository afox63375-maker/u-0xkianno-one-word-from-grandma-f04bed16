# One Word From Grandma — "ChatGP"

The single word a grandma would text about AI: **ChatGP**.

She has heard her grandchild talk about ChatGPT all year, so she texts back about "ChatGP" — the T fell off somewhere between her thumb and the send button, the way it always does. It is warm, a little baffled, and unmistakably hers: the name of the AI she keeps hearing about, typed the way she would actually type it. The dropped T is the whole joke, it only fits AI (it is a typo of ChatGPT, not a word for any subject), and at six letters it is short and instantly readable — fresh where the obvious picks are "Robot" or "Witchcraft".

## Run it

```sh
python3 main.py
```

This writes exactly the word `ChatGP` — and nothing else — to `/output/entry.txt` (creating `/output` if needed), using only the Python standard library.
